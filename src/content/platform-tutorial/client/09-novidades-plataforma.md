# Novidades da plataforma (`/novidades`)

Página com **o que mudou** no Lots BI — novas telas, métricas e melhorias. Atualizada pela equipe Lots após cada entrega relevante.

## Como acessar

- Menu lateral → **Novidades** (ícone de estrela/sparkles)
- URL direta: `/novidades`

## O que encontrar

Cada entrada traz:

| Campo | Conteúdo |
| ----- | -------- |
| **Data** | Quando a novidade entrou em produção |
| **Título** | Nome da funcionalidade |
| **Resumo** | Explicação em linguagem clara |
| **Detalhes** | Lista do que você pode fazer de novo |

A novidade mais recente aparece destacada no topo.

## Exemplo recente (set/2026)

- **Meta Ads — Resultados:** o dashboard Meta Ads mostra a coluna Resultados do Gerenciador (venda, lead, etc.). Use **Puxar métricas** se algum dia estiver vazio.
- **Conexões:** conecte Instagram e Meta Ads você mesmo em **Conexões**.
- **Publicações Instagram:** métricas por post com miniaturas (capítulo **Publicações Instagram**).

Quando houver novidade nova, o sino do topo avisa. Se as notificações do navegador estiverem permitidas para o Lots BI, também aparece um aviso do sistema.

## Dúvidas

- **Como usar uma feature nova?** → Tutorial (menu **Tutorial**)
- **Problema técnico ou dado errado?** → Fale com sua equipe Lots / agência
- **Admin:** changelog completo de engenharia → Knowledge Center (`/admin/knowledge`)
