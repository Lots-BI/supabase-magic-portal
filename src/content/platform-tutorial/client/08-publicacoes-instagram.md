# Publicações Instagram (`/cliente/{slug}/publicacoes`)

Nova área para ver **cada publicação** com foto ou vídeo em miniatura e métricas de desempenho — não confunda com a tela **Instagram** (visão agregada do perfil por dia).

## Como acessar

1. Entre no painel da sua marca (`/cliente/{seu-slug}`).
2. No menu lateral, em **Conta**, clique em **Publicações**.

> Se **Publicações** não aparece, a agência ainda não conectou o Instagram Business ou não há sync concluído. Peça suporte à Lots.

## O que você vê

| Elemento | Significado |
| -------- | ----------- |
| **Miniatura** | Preview do post (Feed, Reel, carrossel ou Story) |
| **Tipo** | Feed, Reels, Carrossel ou Stories |
| **Data** | Quando o conteúdo foi publicado |
| **Métricas** | Alcance, curtidas, comentários, salvamentos, etc. (varia por tipo) |

## Atualizar os números

Use o botão **Puxar métricas** no topo da página.

- Atualiza dados direto do Instagram (via conexão oficial da agência).
- Há um **intervalo mínimo** entre syncs — se aparecer aviso de aguardar, tente de novo em alguns minutos.
- A agência também pode sincronizar pelo painel admin.

## Como interpretar

| Métrica | Dica rápida |
| ------- | ----------- |
| **Alcance** | Quantas contas viram o post |
| **Engajamento** | Interações totais vs alcance |
| **Curtidas / comentários** | Reação direta do público |
| **Salvamentos** | Conteúdo útil — sinal de qualidade |

Compare posts do **mesmo tipo** (Reels com Reels) para decisões de conteúdo.

## Diferença: Publicações vs Instagram (perfil)

| Tela | Foco |
| ---- | ---- |
| **Publicações** | Cada post, com thumbnail |
| **Instagram** (`.../instagram`) | Tendência diária do perfil (visão agregada) |

Use **Publicações** para analisar criativos; use **Instagram** para evolução do perfil no tempo.
