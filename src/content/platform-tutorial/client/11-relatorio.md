# Relatório (`/cliente/{sua-marca}/relatorio`)

O **Relatório** mostra o que aconteceu no período escolhido — em um canvas, não numa análise longa.

## Como abrir

1. Menu lateral → **Relatório**.
2. Ou, em **Dashboards**, o card **Relatório** (quando você tem uma marca).
3. Troque o período no topo (7, 30, 90 dias ou outro recorte).

Os números comparam com a **janela anterior do mesmo tamanho**.

## O que você vê

| Bloco | Para que serve |
| ----- | -------------- |
| **Frase do período** | Uma leitura curta do que aconteceu |
| **Números grandes** | Investimento, resultados, visualizações ou sessões — só o que existir |
| **Pulso** | Evolução dia a dia |
| **Onde foi** | Mix Meta vs Google, ou as campanhas com mais gasto |
| **Tiles das plataformas** | 2–3 números de cada canal ativo, com mini-gráfico |
| **Publicações** | Quantas peças saíram e os destaques em views |
| **Conteúdos** | Publicados vs o que ainda está no calendário |

## Plataforma que não aparece

Se a sua marca **não usa** aquele canal (ou ainda não há coleta no recorte), o bloco **não entra** no relatório. Não há aba vazia de Google Ads, GA4, etc.

## O que este relatório não é

- Não substitui o dashboard completo da plataforma (lá está o detalhe).
- Não inventa métrica: se não coletou, não mostra.
- Não é um PDF exportado — é a tela viva do Lots BI.
